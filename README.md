# Python Task Management System

## Overview

A Python-based task management application designed to allow users to manage tasks through a simple menu-driven system.

The application uses CSV files to store task data and demonstrates fundamental software development concepts including functions, loops, conditional logic, file handling, data validation and debugging.

## Features

- Add tasks
- View tasks
- Complete tasks
- Delete tasks
- View deleted tasks
- CSV data storage
- Input validation
- Menu-driven interface

## Technologies Used

- Python
- CSV
- File handling

## Key Programming Concepts

- Functions and subroutines
- Loops
- Conditional statements
- Lists
- Input validation
- File handling
- Reading and writing data
- Modular programming
- Debugging

## What I Learned

Through this project, I developed practical experience with Python programming, managing data using CSV files, creating reusable functions and debugging errors during development.

I also developed a better understanding of how individual program features can be organised into a larger application.
